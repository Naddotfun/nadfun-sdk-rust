# Branch: `v2`

## Purpose

Add support for the v2 contract generation (`nadfun-contract-v2`) alongside
v1 in the same SDK. Two parallel entry points (`Core` for v1, `CoreV2` for
v2), separate streaming/indexing, and a shared `ApiClient` extended with
v2 endpoints (`get_token`, `get_token_vaults`,
`prepare_token_creation_v2`, version-aware `SaltParams`). No breaking
changes to the v1 public API. SDK does **not** auto-dispatch between
versions — that's a user-side decision documented in
`examples/unified_dispatch.rs`.

## Changes

- **Step 1 — Directory reorg** (`f7d94e1`): moved every v1 module under
  `src/{core,contracts,types,stream}/v1/`; created the v2 scaffold layout
  alongside. Public import paths unchanged via `lib.rs` and per-module
  re-exports.
- **Step 2 — Constants** (`e794968`): restructured `addresses::*` into
  `v1/v2` submodules; added 16 v2 contract addresses for mainnet and
  testnet plus matching `get_*_v2()` helpers.
- **Step 3 — Contract bindings** (`5cc8bd3`): pulled in 4 v2 ABIs and
  wrote alloy-`sol!` bindings for `NadFunFactory`, `NadFunPair`,
  `BondingCurveV2`, `TokenRegistryV2`.
- **Step 4 — SdkVersion enum** (`1978769`): single source of truth for
  the V1/V2 discriminator (wire-form `"V1"`/`"V2"`), used by
  `SaltParams.version` and `ApiTokenInfo.version`.
- **Step 5 — ApiClient v2 extension** (`5858fb3`): added `get_token`,
  `get_token_vaults`, `prepare_token_creation_v2`; optional version field
  on `SaltParams`; shared `upload_image_and_metadata` helper extracted;
  wiremock test suite (`tests/api_v2_endpoints.rs`); merged duplicate
  `ApiTokenInfo` shape.
- **Step 6 — V2 params** (`4297b6c`): added `V2CreateTokenParams`,
  `V2CreatePayment`, `V2TokenCreationResult`, `V2GasEstimationParams`
  on top of the existing trade-param surface.
- **Step 7 — CoreV2 expansion** (`71a0f28`): wired all 4 v2 contract
  bindings into `CoreV2`, added `with_provider` constructor, renamed
  quote methods to `quote`/`quote_in`/`quote_bonding_curve(_in)`/
  `quote_dex(_in)`, added `pool_address`, added `estimate_gas` with a
  full `V2GasEstimationParams` dispatch implemented in
  `NadFunRouter::estimate_gas`, exposed escape-hatch getters
  (`router`/`factory`/`bonding_curve`/`token_registry`/`provider`).
- **Step 8 — `CoreV2::create_token`** (`d503755`): end-to-end orchestration
  (off-chain prepare + on-chain create/createWithNative based on
  `V2CreatePayment`); wiremock test that exercises the full off-chain flow
  (image download, IPFS upload, metadata POST, salt POST with
  `version: "V2"`).
- **Step 9 — Streaming + indexing v2** (`29658f6`): added
  `V2BondingCurveEvent` + `V2EventType` + `decode_v2_bonding_curve_event`;
  `CurveStreamV2` / `CurveIndexerV2`; `NadFunSwapEvent` + decoder;
  `NadFunSwapStream` / `NadFunSwapIndexer`; cross-surface
  `discover_pools_unified` returning `PoolLocation { token, pool,
  surface }`.
- **Step 10 — Examples** (`06e4624`): nine new runnable demos under
  `examples/v2/` plus `examples/unified_dispatch.rs`, all registered in
  `Cargo.toml` and building clean.
- **Step 11 — Docs** (`be85b0e`): CHANGELOG `[Unreleased]` entry,
  llms.txt v2 section, README "Choosing v1 vs v2" section + CoreV2
  Quick Start.
- **Step 12 — This concept doc**.

## Test coverage

35 tests pass at the end of the branch:
- 18 lib unit tests (existing + new v1 trade tests + `version` tests).
- 7 wiremock integration tests (`tests/api_v2_endpoints.rs`) covering
  `get_token` (v2 + v1-default-version), `get_token_vaults`,
  `SaltParams` wire-shape (v1 omission + v2 uppercase), `post_salt`
  round-trip, and the end-to-end `prepare_token_creation_v2` flow.
- 7 typecheck tests (`tests/core_v2_api.rs`) covering V2 params, dex
  type, payment variants, V2CreateTokenParams, V2GasEstimationParams
  variants, and the full CoreV2 async method surface.
- 3 event-signature tests (`tests/v2_events_decode.rs`) confirming
  V2EventType signatures are distinct, distinct from NadFunPair::Swap,
  and that V2BondingCurveEvent enum helpers behave.

`cargo build --all-targets` is clean. All examples (v1 + v2) compile
without modification to v1 examples.
